# Working in this repository

## Commits and pull requests

- **Never mention project names in commit messages, pull request titles or pull request bodies.** This covers client and project names (the ones in `references/lessons.md` and `references/ledger.md`) and the names of the evaluation fixtures under `research/`. Describe the work by its kind instead: "a public-service form evaluation", "a bilingual dashboard fixture", "a bakery's configurator lessons". Earlier commits break this rule; leave them as they are.
